# UX Profile

Generated by `setup-ui-ux-skills`. All UI/UX skills in this project read this file before changing layout, copy, or interaction.

## Aesthetic reference

- **Standard:** Stripe
- **Notes:** Balanced density, strong type hierarchy, tabular figures for changing numbers (seed, timings, confidence, counts), subtle dividers with soft elevation only when needed. Keep the existing dark theme tokens in `frontend/src/app/globals.css` (ink navy canvas `#0a1128`, surfaces `#111b38` / `#1a2547`, pearl cream text `#f3ece0`, electric coral accent `#ff5a4a`). Use coral as the single accent, for primary action, selection and active state only.

## Banned anti-aesthetics

- Gratuitous glassmorphism / `backdrop-filter` without a high-contrast boundary
  - Exception (owner's choice, 28 Nov 2026): the `.glass-tile` / `.glass-tile-sm` cards in `globals.css` over the low-opacity background glows in `page.tsx`. Keep their 1px border and the solid fallback for `prefers-reduced-transparency`; do not add new glass styles elsewhere.
- Floating pastel pill badges for ordinary metadata
- Arbitrary decorative gradients and neon glowing borders
- Multi-color radial rainbow gradients on standard CTAs
- Cartoon empty-state illustrations (people waving / high-fiving)
- Nested scrollbars and icon bloat inside inputs

Known existing violations to clean up when touching those areas: the 2 remaining `bg-gradient-*` usages in `LaunchScreen.tsx`.

## Accessibility target

- **Level:** WCAG 2.1 AA
- **Contrast:** ≥ 4.5:1 for normal text; ≥ 3:1 for large text, UI component borders and focus indicators. Check muted cream-grey text (`slate-400`/`slate-500`) on navy surfaces.
- **Touch / focus:** 44×44px minimum targets (digit picker, slider thumbs, download buttons); keep the 2px coral `:focus-visible` outline with 2px offset on every interactive element.

## Brand tone and microcopy voice

- **Voice:** Utilitarian & Minimal
- **Capitalization:** Sentence case for UI copy and buttons
- **Notes:** Precise, short, no exclamation marks or cheerleading. Verb-first actions ("Generate samples", "Download all"). State facts in status copy ("Backend offline. Retry"), and name the model and numbers in it rather than adjectives.

## Icon library

- **Library:** Lucide
- **Package / path:** `lucide-react` (installed in `frontend/`)
- **Notes:** Replace the Unicode glyph icons (◈ ▦ ◉ ◎ ↓ ↻ ✦) with Lucide equivalents as screens are touched. Stroke icons at 16–20px in dense controls. Don't use other icon sets or emoji/glyphs as UI icons.

## Agent rules

1. Read this profile before creating or editing any UI, CSS, or microcopy.
2. Prefer skills by task: new page → `page-patterns` (name the pattern before markup); layout / chrome → `viewports`; forms → `forms`; overlays → `surfaces`; loaders → `loaders`; empty views → `empty-states`; motion → `motion`. Before finishing UI, run `ux-audit`.
3. Use only the recorded icon library (or project SVG path). Do not mix icon sets or use emoji as UI icons.
4. Never introduce items on the banned list.
5. Destructive actions always use an explicit confirmation dialog.
